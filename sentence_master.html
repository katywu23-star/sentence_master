如何在課堂上分享給學生

方式一：下載 index.html 檔給學生離線使用

點擊下方按鈕將這個網頁下載為單一檔案，學生在平板或電腦上連按兩下即可直接開啟，完全不需要連上外網！

方式二：上傳至 GitHub Pages 生成 QR Code

上傳到 GitHub Repository 後開啟 Pages，產出網址轉成 QR Code 投影在電子白板，學生拿 iPad 掃描即可開始比賽！
