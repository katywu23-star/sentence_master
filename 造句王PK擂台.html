如何在課堂上分享給學生

方式一：直接下載 HTML 檔案給學生

點擊下方按鈕將這個網頁下載為單一 .html 檔案，直接放在隨身碟、學校 NAS、Google Classroom 或教育雲發布，學生在平板/電腦雙擊即可離線開啟並練習！

方式二：上傳至免費靜態託管（生成 QR Code）

將檔案上傳至 GitHub Pages、Netlify Drop 或 Vercel，即可獲得專屬網址。課堂上將網址轉為 QR Code 投影在電子白板，學生拿 iPad 掃描即可開始比賽！
